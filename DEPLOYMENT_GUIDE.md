# 🚀 GitHub Pages Deployment Guide

## Quick Steps to Get Your Running Project Link

### 1. Enable GitHub Pages
1. Go to your repository: https://github.com/chahalshagun/campus-vs-college-
2. Click **Settings** tab
3. Scroll down to **Pages** section
4. Under "Build and deployment", click **Pages**
5. Set the following:
   - **Source**: Deploy from a branch
   - **Branch**: main
   - **Folder**: / (root)
6. Click **Save**

### 2. Wait for Deployment
- GitHub will take 1-2 minutes to deploy
- You'll see a green checkmark when ready

### 3. Your Live Website Link
Once deployed, your website will be available at:
```
https://chahalshagun.github.io/campus-vs-college-/
```

## 🎯 Alternative: GitHub Desktop

## 🔧 Troubleshooting
If GitHub Pages doesn't work:
1. Check if `vite.config.js` has correct base path
2. Ensure build was successful
3. Check repository settings again
