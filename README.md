# College vs Campus 🎓

A comprehensive college search and comparison platform inspired by College Duniya and Zollege. This React-based web application helps students find, compare, and make informed decisions about their higher education choices.

## 🚀 Features

- **Advanced College Search**: Search by college name, course, or location
- **Smart Filtering**: Filter colleges by stream, location, and fee range
- **College Comparison**: Side-by-side comparison of up to 3 colleges
- **Featured Colleges**: Browse top institutions with detailed information
- **Responsive Design**: Modern UI that works on all devices
- **Real-time Statistics**: 50,000+ colleges, 1,000+ courses, 500+ exams

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/college-vs-campus.git
cd college-vs-campus
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🏗️ Build & Deploy

### Build for Production
```bash
npm run build
```

### Deploy to GitHub Pages
1. Push your code to GitHub
2. Enable GitHub Pages in repository settings
3. Select source as "Deploy from a branch" and choose "main"
4. Your site will be available at `https://yourusername.github.io/college-vs-campus`
